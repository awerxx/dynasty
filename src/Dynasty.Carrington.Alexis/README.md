# Dynasty.Carrington.Alexis

Next.js (TypeScript) user-facing UI for the Carrington finance modules. Talks to the
**Dynasty.Carrington.Linda** WebAPI to let individual users add expenses and manage their finances.

The npm package name is `dynasty-carrington-alexis` (npm forbids uppercase); the directory
follows the repo-wide `Dynasty.Carrington.<Module>` convention.

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.
